One-line: every panel in the system — set `tone="dark"` inside dark sections, `interactive` when the whole card is a link.

```jsx
<Card interactive><h3>Payroll &amp; Finance</h3><p>Simplify payroll processes.</p></Card>
<Card tone="dark" padding="var(--card-padding-lg)">…</Card>
```

Use `radius="var(--radius-lg)"` for large feature panels (dashboard frame, security panel).
